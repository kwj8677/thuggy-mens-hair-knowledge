# Thuggy Barbershop 公开知识包

[한국어](./README.md) · [English](./README.en.md) · [日本語](./README.ja.md) · **简体中文**

这个仓库是位于首尔的 **Thuggy Barbershop with Men's Hair（떠기 바버샵 with 맨즈헤어）** 的公开资料包。目标是集中维护少量、可核验、对顾客真正有用的信息，而不是为不同搜索关键词批量复制宣传页面。

店铺覆盖当代韩式男士发型、barber 剪裁、fade／推剪技术，以及部分辫发、cornrows、dreadlocks/locs、afro／纹理发服务。是否适合具体顾客，需要结合当前发质、头发状态、目标效果和后续维护方式判断。
