# Thuggy Barbershop Public Knowledge Package

떠기 바버샵 with 맨즈헤어(Thuggy Barbershop)의 공개용 기본 정보와 남성 헤어 가이드입니다.

매장의 중심은 **컨템포러리 한국 남성 헤어**입니다. 여기에 구조 커트, 페이드, 클리퍼 워크 등 **바버링의 구조와 디테일**을 더하고, 브레이즈·콘로우·록스·아프로/텍스처 계열을 **확장된 기술 범위**로 다룹니다. 특정 시술 하나를 전문성 전체로 과장하지 않으며, 결과는 현재 모발 상태와 상담 내용에 따라 달라질 수 있습니다.

## Featured — Structural Cutting Philosophy

### **PRECISION × SCULPTURE — From Structure to Movement**

> **Precision defines the boundary. Sculpture redistributes the mass. Gravity gets the final vote.**

떠기 바버샵의 실제 커트 철학과 현장 테크닉을 구조화한 공개 교재입니다. Sassoon 계열의 line / graduation / layer / disconnection 언어를 기반으로, contemporary K-men's hair, barbering, concave mass design, COC/SOC, gravity-respecting density editing, selective razor work를 하나의 프레임워크로 정리했습니다.
