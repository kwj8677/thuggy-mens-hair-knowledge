# PRECISION × SCULPTURE — From Structure to Movement

A public, multilingual manual for contemporary Korean men's structural cutting.

> **Precision defines the boundary. Sculpture redistributes the mass. Gravity gets the final vote.**

This project documents a practice-based cutting framework developed from Sassoon-influenced structural thinking, barbering, contemporary K-men's hair, controlled disconnection, concave mass design, gravity-respecting density editing, clipper-over-comb, scissor-over-comb, and selective razor work.

It is **not** an official Sassoon curriculum and does not claim to be a standardized academic theory. It is an independently developed professional framework intended for education, critique, and refinement.

## Core framework

**PSM — Precision Structure × Sculptural Intervention → Motion**

The framework separates haircut problems into distinct variables:

- boundary / line
- length
- density
- mass distribution
- connection / disconnection
- curvature / silhouette
- optical darkness or “color” in short hair
- movement
- gravity / natural fall

The central rule is simple: **do not use one tool to solve every variable.**

## Core manifesto

Clean lines do not require heavy interiors. Disconnection does not have to look disconnected. Thinning should not substitute for structure. A haircut should not only survive the photograph; it should survive movement.
