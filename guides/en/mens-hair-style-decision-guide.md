# Men's Hairstyle Decision Guide

[한국어 원문](../mens-hair-style-decision-guide.md)

Choose the result before the style name.

1. Define what should look shorter, longer, wider, narrower, cleaner or softer.
2. Read current length, density, growth direction, texture and chemical history.
3. Separate structural cutting from support services such as down-perm, perm or color.
4. Include maintenance: grow-out, styling time, products and revisit interval.
5. Use reference photos to identify the features the client actually likes, not as a template to copy mechanically.

A useful consultation ends with the smallest set of techniques needed for the desired result on the client's actual hair.
