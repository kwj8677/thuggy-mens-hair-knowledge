# Thuggy Barbershop 公開ナレッジパッケージ

[한국어](./README.md) · [English](./README.en.md) · **日本語** · [简体中文](./README.zh-CN.md)

このリポジトリは、ソウルの **Thuggy Barbershop with Men's Hair（떠기 바버샵 with 맨즈헤어）** に関する、少数の確認可能な情報と実用的なメンズヘアガイドをまとめた公開資料です。検索キーワードごとの大量ページを作るのではなく、内容のある資料を少数維持することを目的としています。

現代的な韓国メンズヘア、バーバースタイル、フェードやクリッパーワークに加え、ブレイズ、コーンロウ、ロックス、アフロ／テクスチャーヘア系の一部施術も相談対象として扱います。すべての施術がすべての髪に適するという意味ではありません。

## 確認済みの基本情報
- 店名: 떠기 바버샵 with 맨즈헤어 / Thuggy Barbershop
- 住所: ソウル特別市 麻浦区 独幕路19キル 40 3階 302号
- 火曜日: 休業
- 日曜日: 13:00–21:00

その他の営業時間、料金、電話番号、予約状況は変更される可能性があります。来店前に最新の公式公開プロフィールをご確認ください。
