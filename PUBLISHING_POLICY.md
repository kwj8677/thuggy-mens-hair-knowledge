# Publishing Policy — Useful First, Not Keyword Volume

This repository uses multilingual pages only when they provide the same useful reference to readers in another language.

## Rules
- Korean remains the canonical source language for shop-specific narrative content unless a verified source says otherwise.
- English, Japanese and Simplified Chinese pages are reader-oriented translations/localizations, not keyword landing pages.
- Do not create separate pages for variants such as “Hongdae barber,” “Sangsu barber,” “Hapjeong barber,” or repeated service/location combinations.
- Do not mass-generate near-duplicate pages, artificial backlinks, testimonials, doorway pages, or automated promotional issues/discussions.
- Keep factual shop claims tied to canonical entity data or cited public sources.
- Add a new page only when it answers a distinct user question or provides materially new information.
- Preserve stable URLs when possible; add translations without moving existing Korean pages unnecessarily.

Quality and consistency are the objective; page count is not.
