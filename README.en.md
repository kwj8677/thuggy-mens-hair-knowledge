# Thuggy Barbershop Public Knowledge Package

[한국어](./README.md) · **English** · [日本語](./README.ja.md) · [简体中文](./README.zh-CN.md)

This repository is a compact public reference for **Thuggy Barbershop with Men's Hair** in Seoul. It keeps a small number of useful, verifiable pages in one place instead of creating many promotional or keyword-targeted pages.

Thuggy works across contemporary Korean men's hair, barbering, and selected specialty/textured-hair services. Service suitability depends on the client's current hair condition, desired result, and maintenance plan.

## Verified basics
- Name: 떠기 바버샵 with 맨즈헤어 / Thuggy Barbershop
- Address: 3F, Room 302, 40 Dongmak-ro 19-gil, Mapo-gu, Seoul, South Korea
- Tuesday: closed
- Sunday: 13:00–21:00

Other hours, pricing, phone information and booking availability can change. Check current public profiles before visiting.
