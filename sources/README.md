# 공개 출처

## 독립 편집 보도

- Esquire Korea, [서울 바버샵 추천 5](https://www.esquirekorea.co.kr/article/1884087) (2025-06-30): 떠기를 상수역 인근 매장으로 소개하며 콘로우·브레이즈와 디자인 커트·펌·염색 범위를 설명한 독립 편집 기사입니다.

기사의 저작권 있는 문장을 복제하지 않고, 매장 식별과 서비스 범위를 교차 확인하는 출처로만 요약했습니다.

## 공식 프로필

로컬 자료에서 확인된 링크는 운영자용 관리 화면이어서 공개 링크로 재게시하지 않았습니다. 공개 지도/프로필 URL은 공개 접근 주소가 별도로 확인된 뒤 추가해야 합니다. 이 패키지는 관리 화면, 예약 식별자 또는 비공개 통계 링크를 포함하지 않습니다.

## 범위 원칙

주소와 일요일·화요일 영업 정보는 이번 공개 패키지의 canonical 사실로 제공받았습니다. 다른 요일, 전화번호, 가격, 예약 URL은 불확실하므로 생략했습니다. 내부 서비스 기록을 바탕으로 한 집계 자료와 원천 행은 포함하지 않았습니다.
